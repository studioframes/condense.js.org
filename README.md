This official website for [Condense](https://condense.js.org), the high-performance, stateless file optimization and minification engine for [Node.js](https://nodejs.org).

## Getting Started

This site is built with vanilla HTML, CSS, and Javascript.

**Prerequisites:** Node.js >=18

``` bash
npm run dev
```

## Project structure

- [index.html](index.html) — landing page
- [docs.html](docs.html) — documentation page
- [blog.html](blog.html) — blog index
- [changelog.html](changelog.html) — changelog page
- [css/](css/) — site styles
- [js/](js/) — page rendering and UI scripts
- [blogs/](blogs/) — markdown blog source files
- [images/](images/) — site images and icons
