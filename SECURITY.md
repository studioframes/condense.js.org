# Security Policy

## Supported Versions

The Condense website repository is currently maintained as a static site project. Security updates are applied to the latest version of the main branch.

## Reporting a Vulnerability

If you discover a security issue in this repository or the hosted website, please report it privately and responsibly.

Please do not open a public issue for security vulnerabilities. Instead, contact the maintainers directly through GitHub by emailing the repository owner or using the repository’s private reporting channel if available.

Please include:

- a clear description of the vulnerability
- steps to reproduce the issue
- potential impact
- any suggested mitigation

## Disclosure Process

Once a report is received, the maintainers will:

1. review the issue promptly
2. assess the severity and impact
3. work on a fix or mitigation
4. coordinate disclosure in a responsible manner

## Responsible Disclosure

We ask that reporters:

- avoid public disclosure until the issue has been addressed
- refrain from exploiting the vulnerability beyond what is necessary to confirm it
- provide enough detail to help us reproduce and fix the issue
